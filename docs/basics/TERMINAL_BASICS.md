# ターミナルの基礎知識

OpenCode CLI を使うには**ターミナル**（黒い画面）の操作が必要です。
このページでは、プログラミング初心者の研究者の方に向けて、必要な操作だけを最小限にまとめます。

---

## ターミナルとは？

ターミナルは、**キーボードで文字を打ってコンピュータを操作する画面**です。
マウスでクリックする代わりに、**コマンド**と呼ばれる命令文を入力して操作します。

初めて見ると戸惑うかもしれませんが、覚えることは**たった 5 つ**です。

---

## ターミナルの開き方

### macOS の場合

1. **Spotlight 検索**を開く（画面右上の虫眼鏡アイコン、または `Cmd + Space`）
2. 「ターミナル」と入力
3. 「ターミナル.app」をクリック

![Spotlight でターミナルを検索](../images/terminal-spotlight.png)

または：

1. 「アプリケーション」>「ユーティリティ」を開く
2. 「ターミナル」をダブルクリック

> **推奨**: 標準のターミナルよりも **[WezTerm](https://wezfurlong.org/wezterm/)** という高機能なターミナルを使うと、画像表示やドラッグ＆ドロップができて便利です。インストール方法は[CLI インストールガイド](../cli/INSTALL.md)を参照してください。

### Windows の場合

#### 方法 A: Windows Terminal（推奨）

Windows 11 には標準で **Windows Terminal** がインストールされています。

1. スタートメニューを開く
2. 「Windows Terminal」と入力
3. クリックして起動

#### 方法 B: WSL2 上の Ubuntu ターミナル

WSL2 をインストールしている場合：

1. スタートメニューを開く
2. 「Ubuntu」と入力（またはインストールしたディストリビューション名）
3. クリックして起動

#### 方法 C: PowerShell（コマンドプロンプト）

1. スタートメニューを右クリック
2. 「Windows PowerShell」または「ターミナル」を選択

## 絶対に覚えるべき 5 つのコマンド

| 操作 | コマンド | 意味 | 使用例 |
|---|---|---|---|
| 今どこにいるか確認 | `pwd` | 現在のフォルダ（ディレクトリ）の場所を表示 | `pwd` → `/Users/takeru/research` |
| 中身を表示 | `ls` | 今いるフォルダのファイル一覧を表示 | `ls` → `data.csv  analysis.py  paper.tex` |
| フォルダに移動 | `cd` | 別のフォルダに移動 | `cd Documents/research` |
| フォルダを作る | `mkdir` | 新しいフォルダを作成 | `mkdir experiment-2025` |
| ファイルを開く | `open`（Mac）/ `explorer`（Win） | ファイルを Finder / Explorer で開く | `open .`（Mac）/ `explorer .`（Win） |

### よく使うショートカット

| 操作 | キー |
|---|---|
| コマンドの自動補完 | `Tab` キー（例: `cd Docu` と打って `Tab` → `cd Documents`） |
| 前回のコマンドをもう一度 | `↑`（上矢印キー） |
| 処理の中断 | `Ctrl + C` |
| 画面をクリア | `Ctrl + L` または `clear` と入力 |

## ターミナルを使うときの心得

### 1. コピー＆ペーストの方法

- **Mac**: `Cmd + C` / `Cmd + V`
- **Windows**: `Ctrl + C` / `Ctrl + V`（Windows Terminal の場合）
- **ターミナルによっては**: `Ctrl + Shift + C` / `Ctrl + Shift + V`

### 2. コマンドは「料理のレシピ」だと思う

```
cd Documents/research
```
は、「Documents フォルダの中の research フォルダに移動してください」という意味です。
最初は呪文のように見えますが、使っているうちに自然と覚えられます。

### 3. エラーが出ても怖がらない

エラーメッセージは「ここがうまくいきませんでした」というヒントです。
赤い文字が出てもパソコンが壊れることはありません。落ち着いてメッセージを読みましょう。

### 4. 困ったときは

| 症状 | 対処 |
|---|---|
| コマンドが止まらなくなった | `Ctrl + C` で強制終了 |
| どこにいるかわからなくなった | `pwd` で現在地を確認 |
| コマンドが見つからない | `command not found` と出たら、インストールが必要 |

## 最初に練習してみよう

ターミナルを開いたら、以下の順に打ち込んでみてください：

```bash
# 1. 今どこにいるか確認
pwd

# 2. ファイル一覧を見る
ls

# 3. デスクトップに移動（Mac の場合）
cd ~/Desktop

# 4. 練習用フォルダを作る
mkdir opencode-practice

# 5. そのフォルダに移動
cd opencode-practice

# 6. 今の場所を確認
pwd
```

`/Users/あなたの名前/Desktop/opencode-practice` と表示されれば成功です。

## ここまで覚えれば十分

実際に OpenCode を使うときに必要な操作は：

1. 研究プロジェクトのフォルダに `cd` で移動
2. `opencode` と打って起動

この **2 つだけ** です。難しく考えずに進みましょう。
