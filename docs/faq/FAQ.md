# よくある質問（FAQ）

---

## 基本編

### Q: OpenCode は無料で使えますか？

**はい。** 以下の方法で無料で使い始められます：

1. **OpenCode Zen** — 内蔵の無料モデル。API キー不要で即座に使い始められます
2. **ローカルモデル** — 自分の PC で動作する LLM（Ollama など）と組み合わせて完全無料
3. **無料枠のある API** — 各プロバイダの無料枠を利用（GitHub Copilot の無料枠など）

### Q: ChatGPT と何が違うのですか？

ChatGPT は**会話**が得意なのに対し、OpenCode は**コードを書いて実行する**ことに特化しています。OpenCode はあなたの PC のファイルを直接読み書きできるため、研究データの解析やプログラムの実行まで一貫して行えます。

### Q: 日本語で指示しても大丈夫ですか？

**はい。** 日本語で問題なく指示できます。コード内のコメントや変数名、グラフのラベルを英語にするか日本語にするかも指示できます。

### Q: プログラミングができなくても使えますか？

**はい。** OpenCode の最大の強みの一つが、**プログラミングができなくても使える**ことです。日本語で「データをグラフにして」と頼めば、自動的にコードを書いて実行してくれます。コードの意味を聞くこともでき、プログラミング学習にもなります。

## セットアップ編

### Q: Windows と Mac の両方で使えますか？

**はい。** 両方の OS に対応しています。

| OS | インストール方法 |
|---|---|
| **Mac**（Intel / Apple Silicon） | インストールスクリプト、または nix でインストール |
| **Windows** | WSL2 上の Linux 環境で CLI 版、または Desktop 版 |
| **Linux**（Ubuntu, Fedora など） | nix またはパッケージマネージャでインストール |

### Q: WSL2 って何ですか？ 必要ですか？

WSL2（Windows Subsystem for Linux）は、Windows 上で Linux を動かすための仕組みです。OpenCode CLI を使うために必要です。Desktop 版なら WSL2 は不要です。

### Q: インストールがうまくいきません

以下の順に試してください：

1. ターミナルを再起動する
2. [CLI インストールガイド](../cli/INSTALL.md) のトラブルシューティングを確認
3. それでも解決しない場合は、OpenCode の起動後に `/faq` と入力してヘルプを表示

## セキュリティ・プライバシー編

### Q: 研究データが外部に送信されるのですか？

**使用する AI モデルによります。** API 経由でクラウドの LLM（Claude, GPT など）を使う場合、コードやデータの一部がそのサービスに送信されます。データの機密性が重要な場合は：

- **ローカルモデル**（Ollama など）を使う → データは PC から出ていきません
- 機密データを扱う際は、所属機関のポリシーを確認してください

### Q: API キーを他人に見られても大丈夫ですか？

**絶対にダメです。** API キーはパスワードと同じです。以下のことに注意してください：

- API キーを Git リポジトリにコミットしない
- スクリーンショットを撮って共有しない
- `.env` ファイルなどで管理し、`.gitignore` に追加する

### Q: 生成されたコードの著作権は誰にありますか？

**あなたにあります。** OpenCode が生成したコードの権利はあなたに帰属します。ただし、AI が生成したコードをそのまま論文や製品に使用する場合は、所属機関のポリシーや対象ジャーナルのガイドラインを確認することをおすすめします。

## 使用中編

### Q: OpenCode が生成したコードにバグがあります

そのまま伝えてください：

```
「生成されたコードにエラーがあります。
ModuleNotFoundError: No module named 'scipy' と出ました。
どうすればいいですか？」
```

OpenCode が原因を特定し、修正してくれます。

### Q: 処理が途中で止まってしまいました

ターミナルで `Ctrl + C` を押すと強制終了できます。その後、再度 `opencode` で起動し直してください。

### Q: 長い会話をしていると遅くなります

セッションが長くなるとコンテキスト（会話の履歴）が増えて遅くなることがあります。以下のいずれかで対処してください：

- `/new` コマンドでセッションをリセット（会話の履歴は消えますが、ファイルの変更履歴は残ります）
- 「これまでの話は忘れて、新しいタスクに集中してください」と伝える

### Q: 作ったコードやグラフはどこに保存されますか？

OpenCode を起動したフォルダ（研究プロジェクトのフォルダ）の中に、生成されたファイルが保存されます。明示的に保存場所を指定しない限り、カレントディレクトリかそのサブフォルダに作成されます。

### Q: 間違って重要なファイルを消してしまいました

慌てずに、以下のように伝えてください：

```
「さっきの操作で data_original.csv を上書きしてしまいました。
Git で管理しているので、元に戻す方法を教えてください。」
```

OpenCode が Git を使った復元方法を案内します。

## モデル・パフォーマンス編

### Q: どの AI モデルを使うべきですか？

| モデル | おすすめの用途 | コスト感 |
|---|---|---|
| **Claude 4 Sonnet** | 複雑なコード生成、研究全般（**おすすめ**） | 中〜高 |
| **GPT-4o** | 一般的なコード生成、データ解析 | 中 |
| **Gemini 2.5 Pro** | 長いコンテキストが必要な場合 | 中 |
| **OpenCode Zen** | まずは無料で試したい場合 | 無料 |
| **ローカルモデル（Ollama）** | データが PC から出せない場合 | 無料 |

### Q: ローカルモデルでも十分な性能ですか？

簡単なデータ解析やコード生成であれば十分です。ただし、複雑なタスクや大規模なコード生成では、クラウドの高性能モデル（Claude, GPT）の方が良い結果が得られます。

### Q: モデルを途中で切り替えられますか？

**はい。** OpenCode のコマンド `/model` を使うと、セッション中でも使用するモデルを切り替えられます。

## その他

### Q: エラーが出たときのエラーメッセージは英語ですが読めません

エラーメッセージをそのまま OpenCode に貼り付けて、「このエラーの意味を日本語で教えてください」と聞いてください。OpenCode が日本語で説明してくれます。

### Q: MCP って何ですか？

Model Context Protocol（MCP）は、OpenCode が外部のツール（データベース、Web 検索、ファイルシステムなど）と連携するための仕組みです。研究では、論文データベースの検索や実験装置との連携などに使えます。

詳しくは [MCP の利用方法](../cli/MCP.md) を参照してください。
