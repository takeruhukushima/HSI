# 最初の一歩：研究で OpenCode を使ってみよう

このチュートリアルでは、OpenCode をインストールしたあと、実際の研究タスクを通じて使い方を学びます。

> 前提条件: OpenCode のインストールと API キーの設定が完了していること
> - [CLI 版のインストール](../cli/INSTALL.md)
> - [Desktop 版のインストール](../desktop/INSTALL.md)

---

## Step 0: 使う前に知っておくこと

### 「会話」だと思う

OpenCode とのやりとりは**チャット**です。以下のように自然に話しかけてください：

```
あなた：
「実験データが入った CSV ファイルがあるんだけど、
可視化して統計解析もしてほしい」
```

### 「Plan（計画）」と「Build（実行）」の2つのモード

OpenCode には2つのモードがあります：

| モード | 動作 | 使う場面 |
|---|---|---|
| **Plan** 🌱 | コードを書かずに**計画を提案**するだけ | 「どうやって解析すればいい？」と相談したいとき |
| **Build** 🔨 | 実際に**コードを書いて実行**する | 「実際に動かして結果を見せて」というとき |

最初は **Plan モード**で相談しながら進めると安心です。

---

## Step 1: OpenCode を起動する

### CLI 版の場合

ターミナルで、研究プロジェクトのフォルダに移動してから起動します：

```bash
cd /path/to/your/research/project
opencode
```

### Desktop 版の場合

アプリケーションアイコンをクリックして起動します。
画面上部の「フォルダを開く」ボタンから、研究プロジェクトのフォルダを選択してください。

---

## Step 2: 研究データを読み込ませてみる

実際の研究データを使って、OpenCode に解析を依頼してみましょう。

### 例題：気温データの解析

`temperature.csv` というファイルがあると仮定します：

```csv
月,最高気温,最低気温,降水量
1月,8.2,1.8,52.3
2月,9.1,2.3,56.1
3月,12.5,4.9,89.6
4月,18.3,9.7,96.5
5月,23.1,14.6,112.4
6月,26.4,19.1,145.8
7月,30.2,23.4,169.2
8月,31.5,24.1,154.7
9月,27.3,20.3,137.6
10月,21.5,14.5,98.3
11月,15.2,8.2,72.1
12月,10.1,3.5,45.9
```

### Plan モードで相談してみる

まずは **Plan モード**で、どう解析するか相談します：

```
あなた（Plan モード）：
「temperature.csv というデータがあります。
月ごとの最高気温・最低気温・降水量の推移を可視化して、
気温と降水量の相関を分析したいです。
どんなコードを書けばいいですか？」
```

OpenCode が解析計画を提案してくれます。内容を確認し、納得したら「じゃあ実際に書いて実行してみて」と伝えます。

### Build モードで実行する

```
あなた（Build モード）：
「Plan の内容で実際にコードを書いて実行してください。
グラフは論文で使えるように英語表記で、綺麗なデザインでお願いします。」
```

OpenCode が自動的に Python コードを生成し、実行し、グラフを表示します。

---

## Step 3: 追加の指示を出す

結果を見て、さらに改善を依頼できます：

```
あなた：
「グラフのフォントサイズをもう少し大きくしてください。
あと、気温の単位（℃）と降水量の単位（mm）を軸ラベルに追加してください。」
```

**研究では、この「繰り返しの改善」が非常に重要です。** 初回の結果で完璧である必要はなく、どんどん修正を依頼してください。

---

## Step 4: わからないコードを説明してもらう

OpenCode が書いたコードの意味がわからないときは、そのまま聞いてください：

```
あなた：
「さっき書いてもらったコードの、plt.subplots() の行の意味を
詳しく教えてください。Python 初心者でもわかるようにお願いします。」
```

OpenCode はコードの各部分を丁寧に説明してくれます。**これはプログラミング学習にも最強の方法です。**

---

## Step 5: エラーが出たときの対処法

実行中にエラーが出たら、**そのまま OpenCode に伝えるだけ**です：

```
あなた：
「さっきのコードを実行したら、
ModuleNotFoundError: No module named 'pandas' というエラーが出ました。
どうすればいいですか？」
```

OpenCode が原因を特定し、解決方法を提案・実行してくれます。

> **自分でエラーメッセージを検索する必要はありません。** OpenCode がすべてやってくれます。

## 実践的な使用例

### 例1: 実験ノートの自動作成

```
あなた：
「このフォルダにあるすべての実験結果（.csv ファイル）を読み込んで、
各ファイルの要約統計量（平均、標準偏差、最小値、最大値）を
一つの Markdown ファイルにまとめてください。」
```

### 例2: 論文用の図の作成

```
あなた：
「論文用の図を作成したいです。
data.csv の1列目を x 軸、2列目を y 軸にして、
エラーバー付きの折れ線グラフを描いてください。
カラーは白黒印刷でも大丈夫なように、グレースケールにしてください。
解像度は 300 dpi、サイズは 横 6 inch、縦 4 inch で保存してください。」
```

### 例3: LaTeX 論文テンプレート

```
あなた：
「物理学の論文用の LaTeX テンプレートを作成してください。
必要なパッケージは graphicx, amsmath, hyperref です。
タイトル、著者、アブストラクトのセクションを含めてください。」
```

## よくある initial の壁

### 「何から指示すればいいかわからない」

一番簡単な始め方：

```
あなた：
「このフォルダにどんなファイルがあるか調べて、
どんな研究プロジェクトかを要約してください。」
```

OpenCode がフォルダ内のファイルを読み込み、プロジェクトの概要を説明してくれます。そこから「あ、このデータを解析してもらおう」とアイデアが湧いてきます。

---

## まとめ：研究における OpenCode の使い方

1. **起動する** → `cd 研究フォルダ` → `opencode`
2. **相談する** → Plan モードで「どんなコードが必要？」と聞く
3. **実行する** → Build モードで「書いて実行して」と頼む
4. **改善する** → 結果を見て「ここを直して」と追加指示
5. **学ぶ** → コードの意味を聞いてプログラミングを学習
