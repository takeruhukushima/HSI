# 研究ワークフロー別活用例

このページでは、研究のさまざまな場面で OpenCode をどう活用できるかを、具体的なプロンプト例とともに紹介します。

---

## 1. データ解析の自動化

### CSV / Excel データの読み込みと可視化

```
「experiment_results.csv を読み込んでください。
カラムは 'participant_id', 'condition', 'reaction_time', 'accuracy' です。
条件（condition）ごとの反応時間の分布を箱ひげ図で表示し、
同時に条件間の平均反応時間を棒グラフで比較してください。
統計検定（t検定またはANOVA）も実行してください。」
```

### 時系列データの処理

```
「脳波データの時系列が入った EEG_data.csv があります。
1列目が時間（ms）、2〜65列目が電極の電位です。
まず 0.1〜40 Hz のバンドパスフィルタを適用し、
 Cz 電極の波形をプロットしてください。
その後、各周波数帯域（δ, θ, α, β）のパワースペクトルを計算してください。」
```

### データクリーニング

```
「survey_data.csv を読み込んで、以下のクリーニングをしてください：
1. 欠損値（NaN）を含む行を確認・処理
2. 外れ値を Z-score > 3 で検出して報告
3. 各カラムの基本統計量を計算
4. クリーニング前後のデータサイズを比較表示」
```

## 2. シミュレーションコードの作成

```
「心理物理学のシミュレーションをしたいです。
信号検出理論に基づいて、d'（感度）と c（バイアス）を操作したときの
ヒット率とFA率（偽警報率）の関係をプロットするコードを書いてください。
d' を 0.5, 1.0, 1.5, 2.0 の4条件、c を -0.5〜0.5 の範囲で変化させて、
ROC 曲線を描いてください。」
```

---

## 3. 統計解析

### 記述統計と推測統計

```
「data.csv の解析をしてください。
条件Aと条件Bの2群間で、従属変数（score）に有意差があるか検定してください。
正規性検定（Shapiro-Wilk）と等分散性検定（Levene）を行った上で、
適切な統計検定（t検定またはMann-Whitney U検定）を選択・実行し、
結果を論文形式でレポートしてください。」
```

### 相関分析と回帰分析

```
「複数の行動指標の相関行列を計算し、ヒートマップで可視化してください。
さらに、年齢を統制した偏相関分析も実行してください。」
```

## 4. 図の作成（論文品質）

### 論文用マルチパネル図

```
「4つのサブプロットからなる論文用の図を作成してください。
Figure 1: 実験結果の概要図
- パネルA: 条件間の比較（棒グラフ + 個別データ点 + エラーバー）
- パネルB: 経時変化（折れ線グラフ）
- パネルC: 相関プロット（散布図 + 回帰直線）
- パネルD: 結果の模式図（図解）

全体として横2列・縦2行のレイアウトで、統一感のあるデザインにしてください。
カラーは色覚多様性に配慮したカラーパレット（Color Universal Design）を使ってください。
解像度 600 dpi、PDF 形式で保存。」
```

---

## 5. 論文執筆支援

### アブストラクトの作成

```
「実験の概要をまとめます：
- 研究目的：〇〇の認知プロセスを調べること
- 方法：参加者30名、××課題を使用
- 結果：条件間に有意差（p < 0.01）
- 考察：〇〇理論を支持する結果

これらの情報を元に、200語以内の英文アブストラクトを3パターン書いてください。
各パターンで異なる強調点（理論的貢献、方法論的新規性、実用的含意）を前面に出してください。」
```

### LaTeX 関連

```
「Overleaf で使う LaTeX ファイルを準備してください。
以下の内容を含む論文テンプレート：
- タイトル、著者、所属
- アブストラクト
- Introduction（プレースホルダー付き）
- Methods（参加者、課題、手続き）
- Results（図の挿入箇所指定）
- Discussion
- References（bibtex 形式）

スタイルファイルは apa7 を使ってください。」
```

### 参考文献の整理

```
「bibtex 形式の参考文献リストを alphabetic スタイルで整形してください。
各エントリで capital 文字が正しく保持されるように気をつけてください。
エントリは著者のアルファベット順に並べてください。」
```

## プロジェクト全体の構成を作ってもらう

新しい研究プロジェクトを始めるとき：

```
「新しい研究プロジェクト（プロジェクト名: visual_attention_2025）用の
ディレクトリ構造を作成してください。

以下の構成でお願いします：
visual_attention_2025/
├── data/          → 実験データ（生データは raw/、処理済みは processed/）
├── analysis/      → 解析スクリプト
├── figures/       → 生成された図
├── manuscript/    → 論文原稿（LaTeX）
└── docs/          → 実験ノートやメモ

各フォルダに .gitkeep ファイルを置き、analysis/ には
README.md を置いて各スクリプトの説明を書いてください。」
```

## Tips: プロンプトのコツ

各タスクで共通して重要なのは：

1. **目的を最初に言う** → 「何をしたいか」を明確に
2. **ファイル名を正確に伝える** → 曖昧だと誤解されます
3. **制約条件を伝える** → 論文用、カラー制限、解像度など
4. **反復して改善する** → 一度で完璧を目指さない
5. **わからなければ聞く** → 「今のコードの各部分を説明して」と頼める
